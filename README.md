# realize-fansite

RealizE（上海地下偶像团体）的非官方粉丝站,1.0 纯静态、只读展示、本地使用。

## 打开方法

页面通过 fetch 加载公共数据 JSON,需要通过 http 打开(不能直接双击 index.html):

```bash
cd realize-fansite
python3 serve.py
```

然后打开 <http://localhost:8123>。serve.py 除了静态托管还提供编辑页的保存接口;
只看不编辑的话 `python3 -m http.server 8123` 也行。

## 编辑数据(edit.html)

<http://localhost:8123/edit.html>(首页页脚也有入口)。团体资料、成员资料(名字/罗马音/
emoji/应援心/应援色/生日/介绍/链接)、演出记录、大事纪都在这里改:

- 表格里直接改字段、勾缺席/特别场,顶部表单添加新条目,行尾 🗑 删除
- **所有改动先进底部的「待保存改动」面板**——新增/修改/删除逐条列出,
  修改精确到字段(`特别场:否 → 是` 这种),确认无误再点「保存到文件」才真正写入
- 「放弃改动」一键回到文件里的状态;每条改动旁还有「撤销」可**单独反悔一条**
- **输入有校验**:生日(月-日)、应援色(#rrggbb)、各类链接(http 开头)格式不对时
  红字提示且不允许保存
- **并发保护**:保存时核对文件哈希,如果数据已被别的标签页(或手工)改过,
  拒绝覆盖并提示刷新重做
- **改名会级联**:成员或团体改名时,演出缺席、大事纪关联里的旧名字自动一起改;
  场地改名会同步更新演出上的场地名;删除成员也会把名字从引用里移除
- 保存走 serve.py 的 `POST /api/save`(只监听本机、只允许写这两个 JSON);
  线上部署没有这个接口,编辑页在线上天然只读

注意:`tools/import.py` 会**整体覆盖**这两个 JSON。既然网站已是权威数据源,
以后日常编辑建议都走 edit.html;import.py 只在想从 star-tracker 批量搬历史数据时用,
用之前先确认网站上没有未同步回 star-tracker 的改动。

## 页面内容

- **Hero**:官方 logo、团名、简介、下一场演出倒计时(含场地和地址)、统计、官方/经纪人/微博群链接
- **成员**:五张成员卡(应援色、代表物、生日、初舞台、出席统计、微博链接),顺序与团体公式照对位
- **演出档案**:倒序列表分页显示(每页 10 场),自动编号"第N场",特别场高亮,显示场地,
  出席成员用 emoji 显示(缺席置灰),可按成员筛选
- **大事纪**:events + 有备注/特别场的演出合并成一条时间线
- **维护兜底**:任一数据文件加载失败时整页显示维护提示(公式照 + 重试按钮);
  URL 加 `?maintenance` 可预览
- "今天"的判定统一按**北京时间**(UTC+8)计算

## 数据:公共 / 个人 严格隔离

本仓库只存**公共记录**,是对外的权威数据源;个人记录(初见/初切/チェキ/成员小记)
只存在于各自的 star-tracker 本地,永远不进这个仓库。

- `data/shows.json` —— **公共**:演出记录(id/日期/时间/场地/备注/特别场/缺席)
- `data/events.json` —— **公共**:大事纪(id/日期/标题/备注/关联成员)
- `data/site.json` —— **公共**:团体资料 + 成员资料(名字/罗马音/emoji/应援心/应援色/
  生日/代表物/出身/链接)+ 里程碑规则(里程碑没做进编辑页,要改直接改文件)
- `data/venues.json` —— **公共**:场地库(名称/地址/交通/备注),演出按场地名关联

全部通过 edit.html 编辑,不用手改文件。**本站即公共记录的权威源**;
shows/events 两份 JSON 同时是**公开订阅源**,部署后 star-tracker 可 fetch 并按 id 合并。
(早期从 star-tracker 批量导入的 import.py 已随 schema 演进删除,历史见 git。)

## 目录结构

```
realize-fansite/
├── index.html          页面骨架
├── edit.html           本地编辑页(带待保存改动预览)
├── serve.py            本地服务器(静态托管 + 编辑保存接口)
├── css/style.css       样式(颜色集中在 :root 变量,换肤只改这里;规范见 STYLE.md)
├── assets/             logo、公式照、favicon 等图片(originals/ 存原始文件)
├── data/
│   ├── site.json       团体 + 成员资料(公共)
│   ├── shows.json      公共演出记录(亦是对外订阅源)
│   ├── events.json     公共大事纪(同上)
│   └── venues.json     场地库
├── js/
│   ├── derive.js       纯数据推导(编号/出席/里程碑/时间线/北京时间),不碰 DOM
│   ├── app.js          入口:读数据、渲染各区块、筛选与分页
│   ├── fallback.js     数据加载失败时的维护兜底页
│   ├── edit-diff.js    待保存改动对比 + 数据校验(纯函数)
│   └── edit.js         编辑页:表格编辑、改动面板(含单条撤销)、保存
├── tools/publish.sh    一键 commit + push
└── test/               单元测试(node --test)
```

## 运行测试

```bash
node --test test/derive.test.js
```
