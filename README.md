# RealizE 粉丝应援站 ✨

给上海地下偶像 **RealizE**(七韵IdolProductions 旗下)的非官方应援站,由粉丝用爱发电维护。

## 🔗 直接访问

**<https://tommychenyixiao.github.io/realize-fansite/>**

手机电脑都能看,不用安装任何东西。

## 💜 这里有什么

- **演出档案**:出道以来每一场演出的日历/列表,场地、地址、出席成员、当场 setlist,
  点日历上的场次就能看详情——回忆杀和查档一站搞定
- **成员图鉴**:五位成员的高清写真、担当色、生日、MBTI、微博置顶的自我介绍,
  以及她们的微博 / B站 / 抖音 / 小红书 / 粉丝群直达链接
- **歌曲**:RealizE 唱过的每一首歌(标注原唱),还有每首歌的披露次数统计
- **情报**:近期演出与活动公告
- **影像 / 大事纪**:官方视频合集、团史时间线(团名初披露、出道日、成员加入……)
- **下一场演出倒计时**:打开首页就知道离下次见面还有几天 🎫

日程与"今天"的判定统一按北京时间;演出信息以
[官方微博](https://weibo.com/n/RealizE_Project) 为准,本站不涉及任何票务交易。

## 🙋 发现错误 / 想补充内容?

站内信息(场次、setlist、成员资料等)都是人工整理的,难免有疏漏:

- 会用 GitHub 的同担:欢迎提 [Issue](../../issues) 指出问题,或直接改动数据提 PR
  (任何人都可以提交,站长确认后合并上线)

尤其欢迎补充:历史场次的 setlist、每首歌的 call 表、现场照片线索。

## 🛠 技术同担看这里

纯静态站(HTML/CSS/vanilla JS,零依赖零构建),数据全部是仓库里的 JSON——
`data/` 目录本身就是公开数据源,想做衍生工具(比如出席记录 App)可以直接 fetch。

本地跑起来:

```bash
python3 serve.py          # → http://localhost:8123
```

本地模式下首页页脚会出现「✏️ 编辑数据」入口:表格化编辑全部数据,
带改动预览(diff 确认后才写盘)、格式校验、改名级联、并发保护;
线上没有保存接口,编辑页天然只读。

改代码请先读:

- `PLAN.md` —— 路线图(已完成 / 计划中)
- `STYLE.md` —— 视觉规范(梦幻淡紫色系、字体铁律,请勿破坏)
- 约定:功能改动走 branch + PR;新增内容类型 = 新 JSON + 渲染 + 编辑页 + serve.py
  白名单四件套;改完跑 `node --test test/*.test.js`,UI 改动需桌面 + 手机
  (`tools/mobile-preview.html`)双端确认
