# RealizE 粉丝应援站 ✨

给上海地下偶像 **RealizE**(七韵IdolProductions 旗下)的非官方应援站,由粉丝用爱发电维护。

## 🔗 直接访问

**<https://realizefansite.com>**

手机电脑都能看,全站 HTTPS,不用安装任何东西。

## 💜 这里有什么

- **演出档案**:出道以来每一场演出的日历/列表——场地、地址、出席成员、当场 setlist,
  点日历场次或列表任意一行都能看详情;回忆杀和查档一站搞定
- **出道纪念日**:日历上自动标出团体和成员的出道整百天、520/666、周年纪念
  (金粉角标是团体的,应援色角标是成员的),可一键筛选只看演出或只看纪念日
- **📅 日历订阅**:演出档案区点「🔔 订阅」,把全部排期和纪念日同步进你的手机日历——
  之后站里每次更新排期,你的日历自动跟着变,不用天天来翻
- **成员图鉴**:五位成员的高清写真、担当色、生日、MBTI、出道履历(出道日 · 出道至今 ·
  生涯出演),以及她们的微博 / B站 / 抖音 / 小红书 / 粉丝群直达链接
- **歌曲**:RealizE 唱过的每一首歌,标注原唱
- **情报**:演出预告与活动公告(过期自动下线,看到的永远是新鲜的)
- **影像 / 大事纪**:官方视频合集、团史时间线(团名初披露、出道日、成员里程碑……)
- **下一场演出倒计时**:打开首页就知道离下次见面还有几天 🎫

日程与"今天"的判定统一按北京时间,倒计时、日历、纪念日全部自动推移;
演出信息以 [官方微博](https://weibo.com/n/RealizE_Project) 为准,本站不涉及任何票务交易。

## 🛠 技术同担看这里

纯静态站(HTML/CSS/vanilla JS,零依赖零构建),数据全部是仓库里的 JSON——
`data/` 目录本身就是公开数据源,`/shows.ics` 是标准 iCalendar 订阅源,
想做衍生工具(比如出席记录 App)可以直接 fetch。

本地跑起来:

```bash
python3 serve.py          # → http://localhost:8123
```

本地模式下首页页脚会出现「✏️ 编辑数据」入口:表格化编辑全部数据,
带改动预览(diff 确认后才写盘)、格式校验、改名级联、并发保护;
线上没有保存接口,编辑页天然只读。

改代码请先读:

- `docs/PLAN.md` —— 路线图(已完成 / 计划中)
- `docs/STYLE.md` —— 视觉规范(梦幻淡紫色系、字体铁律,请勿破坏)

约定:

- **所有改动(含数据)一律走 branch + PR**,master 受保护不可直推,仅本站管理员可审批合并
- 新增内容类型 = 新 JSON + 渲染 + 编辑页 + serve.py 白名单,四件套缺一不可
- 改了 `shows / venues / site` 数据要跑 `node tools/build-ics.js` 重建订阅文件
  (用 `tools/publish.sh` 发布则自动处理,忘了测试也会拦住)
- 改完跑 `node --test test/*.test.js`;UI 改动需桌面 + 手机
  (`tools/mobile-preview.html`)双端确认后再提交
